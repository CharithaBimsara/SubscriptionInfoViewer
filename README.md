# Subscription Info Viewer

Minimal Java Android app that opens the configured 3x-ui subscription-info URL inside a WebView.

Default URL:
https://168.107.81.142:2096/64ojfjhx749zdo1k/ldhs194h0xy8f5dq

The app does not bypass TLS certificate errors or implement a VPN/proxy itself; it only displays the subscription page provided by the server.
